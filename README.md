# Twelve Angry Models

Public teaching materials for *Twelve Angry Models*.

This repository hosts:

- the compiled book PDF (`twelveAngryModels.pdf`)
- compiled course slides (PDFs under `slides/`)
- JASP analysis files under `jasp/` (organized like COGS107/code with slides-style numbering: `jasp/01-successRate/<example>/`, …)

The OSF project remains archival. Source LaTeX, MATLAB, and working figure trees are not published here.
